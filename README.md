# Smart Campus Resource Booking System

## Project Description

The Smart Campus Resource Booking System is a Python application developed to help manage campus resources and bookings. It uses Tkinter for the graphical user interface and SQLite to store information.

## Main Features

- User registration and login.
- Different user roles: Lecturer, Campus Administrator, and System Operator.
- Campus resource management.
- Resource booking and booking history.
- Campus-specific booking rules.
- Booking reports.

## Technologies Used

- Python
- Tkinter
- SQLite
- PyCharm

## Project Files

- `main.py` – Starts the application.
- `gui.py` – Contains the graphical user interface.
- `database.py` – Handles database operations.
- `models.py` – Defines user and resource classes.
- `booking_rules.py` – Contains campus booking rules.

## How to Run the Application

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in PyCharm.
4. Run `main.py`.
